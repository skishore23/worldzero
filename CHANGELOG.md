# Changelog

This project follows semantic versioning for the public Python and CLI interfaces. Family behavior, calibration suites, scoring profiles, and persisted schemas carry independent versioned identities.

## 0.3.0 — 2026-09-01

- Added the typed `LawFamily` SDK and deterministic exact-ID registry.
- Added official catalysis, inhibition, delayed-transformation, and matched-null families.
- Moved family transitions behind a fixed kernel boundary with immutable views and atomic validation.
- Added state-v3 snapshots, trace-v4 identity freezing, exact plugin replay, generic controls, and central scoring.
- Added `FamilyTestKit`, `worldzero laws` commands, and an installable community plugin example.
- Preserved tested state-v2 and trace-v2/v3 compatibility fixtures.
- Added public architecture, contribution, governance, security, support, history, and reference-evidence documentation.

## 0.2.0

- Established the stochastic world, observation-only reference policies, causal controls, replay, and local observatory used by the early research prototypes.
