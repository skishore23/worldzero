Let the world run with nobody in it.

After the creator dies, its private memory is erased. All three branches advance through the same uninhabited interval and receive identical scheduled environmental proposals.

The important observation is output while no living agent and no policy calls exist. A useful arrangement is not just a saved explanation: it changes what happens next.

For the successor test, extra resource stocks generated during this interval are removed by matching every branch to the same resource array. This isolates ongoing infrastructure from an inherited pile of food.
